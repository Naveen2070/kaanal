# kaanal

Kaanal (கானல், "mirage") is a single binary that pretends to be your backend: OpenAPI mocks with realistic data, simulated service and database timing, live chaos, and a graphical editor with a load simulator.

```bash
npx kaanal demo            # a demo shop with a chaos bar in your browser
npm install -g kaanal      # then: kaanal up -c kaanal.yaml
```

This package only picks the right prebuilt binary for your system (Linux x64, macOS arm64, Windows x64). Documentation, source and issues: https://github.com/Naveen2070/kaanal
