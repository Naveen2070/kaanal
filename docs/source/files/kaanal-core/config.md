# `crates/kaanal-core/src/config.rs`

Parsing of `kaanal.yaml` into typed config.

## What it does

Defines the serde types that mirror the YAML file, plus `Config::from_yaml` which parses and reports errors as `file:line:col: message` (rule R6.1 — the caller prepends the file name). `nodes:` is a map of `type`-tagged nodes (rule R1.15): each kind is its own struct with `deny_unknown_fields`, so a field on the wrong kind (or a typo) fails at load instead of being silently ignored. Single values are checked here (ranges, `p50 ≤ p99`, URL shape); every type also derives `schemars::JsonSchema`, from which the editor schema is built ([schema.md](schema.md)).

## Types (YAML shape)

```yaml
version: 1 # Config.version — must be 1
seed: 42 # Config.seed — RNG seed, default 0
port: 8080 # Config.port — default 8080
nodes: # IndexMap<String, NodeConfig> — insertion order preserved
  gw: { type: gateway, flavor: nginx, proc: 1ms, concurrency: 8 }
  app: { type: service, spec: openapi.yaml, proc: 2ms, concurrency: 4 }
  mono: { type: monolith, spec: openapi.yaml, proc: 3ms, flavor: mysql, ops: { read: 1ms }, concurrency: 2 }
  db: { type: database, flavor: postgres, ops: { write: 9ms }, concurrency: 16, pool: { size: 10, queue: 5, overflow_status: 504 } }
  cache: { type: cache, flavor: redis, hit_ratio: 0.8, hit: 1ms, miss: 2ms, ttl: 30s, concurrency: 32 }
  pay: { type: external-api, proc: 50ms, error_rate: 0.01, rate_limit: { rps: 100, burst: 20 }, proxy: "https://api.example.com", pool: { size: 4 }, concurrency: 4 }
  login: { type: auth, proc: 5ms, token_ttl: 2h, concurrency: 2, users: [{ username: alice, password: secret, roles: [admin] }, { username: bob, password: pw }] }
edges: # Vec<EdgeConfig>
  - { from: app, to: db, net: 1ms, calls: 2 }
routes: # IndexMap<String, RouteOverride> — static overrides
  "GET /health": { status: 200, body: { ok: true } }
```

## Items

| Item                     | Kind   | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Config`                 | struct | Top-level file. `version`, `seed` (default 0), `port` (default 8080 via `default_port`), `nodes`, `edges`, `routes`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `NodeKind`               | enum   | The seven kinds: `Gateway`, `Service`, `Monolith`, `Database`, `Cache`, `ExternalApi`, `Auth`. `as_str()` gives the YAML spelling (`external-api`); `Display` prints the same.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `NodeConfig`             | enum   | One node, internally tagged by `type` (kebab-case), one struct per kind. Accessors `kind()`, `proc()`, `spec()`, `concurrency()`, `flavor()` (free text on a gateway, the preset name on database/monolith/cache). An unknown `type` lists the seven kinds.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `GatewayConfig`          | struct | `flavor` (free-text label such as `nginx`, not a preset), `proc`, `concurrency`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `ServiceConfig`          | struct | `spec`, `proc`, `concurrency`. Never has `ops`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `MonolithConfig`         | struct | `spec`, `proc`, `ops`, `flavor` (`DbFlavor`), `concurrency`. Has inline ops when it sets `ops` or `flavor`; inline ops are used once endpoint chains land (A2).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `DatabaseConfig`         | struct | `ops`, `flavor` (`DbFlavor`), `concurrency`; `pool` is validated, no effect yet (B).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `CacheConfig`            | struct | `flavor` (`CacheFlavor`), `hit_ratio` (0 to 1), `hit`, `miss`, `concurrency`; `ttl` is validated, no effect yet (later). Costs are used once endpoint chains land (A2).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `ExternalApiConfig`      | struct | `proc`, `concurrency`; `error_rate` (0 to 1), `rate_limit`, `proxy` (`http(s)://…`) and `pool` are validated, no effect yet (B / later).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `AuthConfig`             | struct | `proc`, `concurrency`; `users` (unique usernames) and `token_ttl` (`Option<Duration>`, at most 1 day; the 1 h default is applied by E) are validated, no effect yet (E).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `OpsConfig`              | struct | `read`/`write`/`scan`, all optional here; completeness (user value > flavor preset > `MissingOps`) is checked in [topology.md](topology.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `DbFlavor`/`CacheFlavor` | enum   | `postgres` \| `mysql` \| `mongodb` and `redis` \| `memcached`. Typed, so serde lists the valid names for an unknown or wrong-family flavor. `as_str()` gives the YAML spelling. Values in [presets.md](presets.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `PoolConfig`             | struct | `size` (`NonZeroU32`), `queue` (default 0), `overflow_status` (500–504, default 503).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `RateLimitConfig`        | struct | `rps` (finite, above 0), `burst` (`NonZeroU32`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `UserConfig`             | struct | `username`, `password`, `roles` (default empty). Synthetic accounts only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `concurrency` (any kind) | field  | `Option<NonZeroU32>`: most simultaneous own hops. `0`, negatives and fractions are rejected with a position. Honoured by the simulator; live mode warns and ignores it for now.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `EdgeConfig`             | struct | `from`, `to` node names, optional `net` latency, `calls` (`NonZeroU32`, default 1; calls per request along the edge, used from A2).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `DistConfig`             | enum   | A duration in YAML: `Fixed(Duration)` (`5ms`), `Pct { p50, p99 }` (`{ p50: 4ms, p99: 20ms }`) or `Exp { mean }` (`{ mean: 5ms }`). Custom `Deserialize` impl replaces serde's useless untagged-enum error with "expected a duration like `5ms`, `{ p50: 1ms, p99: 3ms }` or `{ mean: 5ms }`". Map shapes reject unknown keys, so `{ mean: 5ms, p99: 9ms }` is an error. Durations use `humantime_serde`. Any duration (or p99, or mean) over `MAX_DURATION` = 1 h is rejected with its line, so summed hops can never overflow `Duration`. `{ p50, p99 }` with p50 above p99 is rejected (closes the M0 review question); equal is fine. Its JSON Schema is hand-written (`Distribution`, see [schema.md](schema.md)). |
| `RouteOverride`          | struct | Static response for a `"METHOD /path"` key: `status` (default 200) and `body` (any JSON).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `ConfigError`            | struct | `line`/`col` (optional) + `msg`. `Display` prints `line:col: msg` when a position is known.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `Config::from_yaml(src)` | fn     | Strips a UTF-8 BOM (Windows editors add one; YAML rejects it — rule R6.4), parses with `serde_yaml_ng`, maps serde's location into `ConfigError`, rejects `version != 1`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## Notes

This file only _parses_ and checks single values. Field placement (`ops` on a service, `spec` on a gateway) is now a parse error, since each kind has its own strict struct. Semantic validation (gateway count, edges, DAG, ops that presets must complete) lives in [topology.md](topology.md); route/spec wiring happens in [state.md](../kaanal-server/state.md). Errors inside a node are positioned at the start of `nodes:` by serde for now.
