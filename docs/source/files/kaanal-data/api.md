# `crates/kaanal-data/src/api.rs`

OpenAPI 3.0.x → `ApiModel`: the list of endpoints the server will mock.

## What it does

Parses a spec (YAML or JSON — YAML is a superset) into one `Endpoint` per `path × method`, picking the success response and inlining every local `$ref` in its JSON schema, so downstream code never has to resolve references.

Phase one supports **3.0.x only**; 3.1 is rejected with a clear message.

## Types

| Item                 | Kind   | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Endpoint`           | struct | `method` (uppercase), `path` (OpenAPI template, also valid matchit 0.8 syntax), `status` (chosen 2xx), `schema` (response JSON schema with refs inlined; `None` = no JSON body), `query_params` (`Vec<QueryParam>`, see below), `file_in` and `file_out` (the request body or a 2xx response is a file: `multipart/*`, an octet stream, an image, audio, video, a PDF or zip, or a `format: binary` schema; `warnings()` then asks for `req_bytes` / `resp_bytes`, RULES 65). |
| `QueryParam`         | struct | One primitive (integer, number, string, boolean) query parameter: `name`, `minimum`/`maximum`/`default` (`Option<i64>`, read from its schema) and `numeric` (integer or number). Re-exported at the crate root.                                                                                                                                                                                                                                                               |
| `ApiModel`           | struct | `endpoints: Vec<Endpoint>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `MAX_REF_EXPANSIONS` | const  | 10 000 — cap on `$ref` expansions per schema (see below).                                                                                                                                                                                                                                                                                                                                                                                                                     |

## Functions

| Function                                  | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ApiModel::from_openapi(src)`             | Parses the document; extracts the version (accepting unquoted `openapi: 3.0`, which YAML reads as a number); rejects non-3.0.x; walks `paths` for the 7 HTTP methods; each path must start with `/`. A path-item `$ref` is followed with `deref` (an external one fails loudly) instead of dropping the route.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `pick_response(op, doc, ptr)`             | Chooses the **lowest 2xx** response code (404s etc. are ignored; no 2xx → `(200, None)`). Follows a response-level `$ref` chain with `deref`, then digs out `content.application/json.schema` and inlines it. `ptr` is the JSON-pointer of the operation, used in error messages.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `inline(v, doc, ptr, stack, budget)`      | Recursively replaces every local `$ref` with its target. Two safety rails: `stack` detects **cycles** (recursive schemas → error on first revisit, even through fan-out), and `budget` caps total expansions so an acyclic but exponentially-branching ref chain ("billion laughs") is rejected instead of eating memory. Both errors name the operation pointer.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `deref(v, doc, ptr)`                      | Follows a `$ref` chain (`A → B → target`) to the first value that is not a ref (R6.10e). Used for response objects and path items. A ref seen twice is a cycle and fails ("recursive $ref"), so `A → B → A` cannot hang.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `carry_examples(media, schema, doc, ptr)` | A media type's `example`/`examples` replace the schema's own (they are more specific): `example` is copied onto the schema, an `examples` map (`name: { value }`, each entry followed through `$ref`) becomes an array of its values. A dangling `$ref` there fails the load with a position. The generator then reads them first (D1.8).                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `query_params(item, op, doc, ptr)`        | The operation's `in: query` parameters whose `schema.type` is `integer`, `number`, `string` or `boolean` (a query parameter's `schema` may be a `$ref`; one that does not resolve skips the parameter, and other locations are never resolved; a string with a `date`, `date-time` or `time` format is a filter and is skipped), in document order: path-item parameters first, then the operation's, where a same-named operation parameter replaces the path-item one in place. Entries are followed through `$ref` with `deref`; an entry that does not resolve (external, dangling or cyclic) is skipped, never a load error, for every method (a spec that loaded before D3 still loads); header/path and non-primitive parameters are skipped silently. Never fails. Feeds paging (D3). |
| `tag_branches(src, out)`                  | A `discriminator.mapping` names its branches by `$ref`, which inlining erases. So each inlined `oneOf`/`anyOf` branch the mapping names (by full `#/components/schemas/X` or bare `X`) is rewritten to `allOf: [branch, { properties: { <tag>: { type: string, enum: [keys] } } }]`; the generator's `enum` then sets the tag and the branches become mutually exclusive for `oneOf` validation. A branch named by several keys gets all of them. Unnamed branches are left alone (`warn` reports them). Amends design 11a item 3 (R1.52c).                                                                                                                                                                                                                                                   |
| `base_path(doc)`                          | The path of the first `servers` entry (`/api/v3` for `url: /api/v3` or `https://host/api/v3/`); empty when there is no usable server or its path is `/`. `from_openapi` puts it in front of every `paths` key, so the route registry, chaos keys and `endpoints:` keys all see the full path (R1.61). Errors if the path is still a template.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `fill_variables(url, server)`             | Replaces each `{name}` in the server URL with that server variable's `default`; a variable with no default (or an unclosed `{`) is an error.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `resolve_ref(r, doc, ptr)`                | Local refs (`#/...`) only, resolved as JSON pointers. External refs (`other.yaml#/...`) are rejected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Error behaviour

Every failure names the operation (`/paths/~1users/get`) and says exactly what is wrong: unsupported version, external `$ref`, recursive `$ref`, missing target, too many expansions. Covered by `kaanal-data/tests/api.rs` (see [../tests.md](../../tests.md#crateskaanal-datatestsapirs)).
