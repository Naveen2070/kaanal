# `crates/kaanal-server/src/site.rs`

The `site:` folder: static files served from the same origin as the mocks (spec C11). User page: [../../../web/static-site.md](../../../web/static-site.md).

## What it does

`AppState::build` opens the folder once (`Site::open`); [mock](mock.md) `handle` calls `serve` for every non-control request whose path no spec route matches, before the request takes an id. A `Some` answer is returned as is; `None` falls through to the mock, so a missing file is the mock's own 404. Site files never reach the engine, the log, the event bus or a route counter, and get no CORS headers.

## Items

| Item                           | Kind     | What it does                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Site`                         | struct   | The folder's canonical path (`root`, private).                                                                                                                                                                                                                                                                                                                                                   |
| `Site::open(base_dir, rel)`    | fn       | Refuses an absolute `rel`, a missing path, a file, the project folder itself, and anything that canonicalises outside `base_dir` (so `..` and symlinks out). The message names `site:` and the value.                                                                                                                                                                                            |
| `Site::root()`                 | fn       | The canonical folder.                                                                                                                                                                                                                                                                                                                                                                            |
| `safe_join(root, url_path)`    | fn       | Percent-decodes once; `None` for `\0`, `\`, a `..` segment, a segment with `:`, or a first decoded segment equal to `__kaanal` (ASCII case-insensitive). Pushes the other segments (empty and `.` skipped, so `//x` stays under `root`); a trailing `/` or a folder means its `index.html`. Canonicalises and returns the path only if it is a regular file under `root` (symlinks out refused). |
| `serve(site, method, path)`    | async fn | `GET`/`HEAD` only. Runs `safe_join` and the read on the blocking pool (the `fs` feature of tokio is not enabled). Headers: `Content-Type`, `Cache-Control: no-cache`, `X-Content-Type-Options: nosniff`. hyper drops the body of a `HEAD`.                                                                                                                                                       |
| `content_type(file)` (private) | fn       | A fixed table by lowercase extension (html, css, js/mjs, json/map, txt, svg, png, jpg/jpeg, gif, webp, ico, woff, woff2); anything else `application/octet-stream`.                                                                                                                                                                                                                              |
