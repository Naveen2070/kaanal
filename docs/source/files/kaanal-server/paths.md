# `crates/kaanal-server/src/paths.rs`

Whose text a config is, and what the files it names may be. Moved out of [generation](generation.md) (R3.8) with its tests; the code is unchanged.

## What it does

A person who wrote the config file may point `spec:`, `data:` and `endpoints:` anywhere they can read. A draft that arrived through the control API may not: the API must not become a way to make the server read other files and report what it found (R1.71).

| Item                                  | Kind | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Trust`                               | enum | `Owner` (startup, `check`, `selfcheck`): paths are taken as written. `Api` (a draft): `spec:`, `data:` and `endpoints:` must be relative, without `..`, and must not leave the project through a link; messages show paths relative to the project; a scenario file that does not resolve is flagged instead of failing. Re-exported by `generation`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `resolve(base_dir, rel, trust, at)`   | fn   | `rel` under `base_dir`. For `Api`: refuses an absolute path, a root, a drive prefix, `..`, and a path whose canonical form is outside the project; the message repeats only what the draft said.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `shown(base_dir, file, trust)`        | fn   | A path as a message names it: as is for the owner, relative to the project for the API (`draft::apply::relative`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `read_text(path)`                     | fn   | The text of a regular file, at most 16 MiB (`MAX_FILE_BYTES`), for every trust, so a path to a device or an enormous file cannot exhaust memory.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `confine(text, base_dir)`             | fn   | Checks the files a config _text_ names (`nodes.*.spec`, `data`, `endpoints`) against the `Api` rule without building anything; Save runs it for every Save. The text is read as YAML with `serde_yaml_ng` (the library the loader uses) with anchors, aliases and merge keys applied, so every spelling of a path reaches the check as the value the loader will see. It does not use `Config::from_yaml`, so YAML that fails a semantic check there still has its paths checked. It fails closed: every node is checked whatever type its key has (the loader reads `1:` or `true:` as a name), a scalar path of any type is checked as the text the loader would use, and a path that is a list or a map (or `data` as a map) is refused, not skipped; an inline `endpoints:` map is not a path. Only text that is not YAML at all passes: nobody can load it. |
| `scalar_text`, `check_path` (private) | fns  | A scalar as the loader would read it for a `String`; one path value held to the rule.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
