# `crates/kaanal-server/src/generation.rs`

`Generation`: everything one config builds, the part of the server a later Apply can swap.

## What it does

`Generation::build(cfg, base_dir, drawn_seed, trust)` is the full load pipeline shared by `serve` and `check` (`kaanal validate`): topology → OpenAPI specs → endpoints (inline map or the endpoints file) → scenarios → route table. It returns the generation and the `ScenarioSet` the config and `scenarios/` define, resolved against this topology. Moved out of `state.rs` unchanged (R3.8); `AppState` holds the result behind a lock and hands it out one `Arc` at a time (Studio step 2, part 2a), so a later Apply can swap it.

`drawn_seed` is the `determinism: realistic` startup draw, passed in rather than drawn here so it stays the same across generations. `chain_seed` is `drawn_seed` if given, else `seed:`.
