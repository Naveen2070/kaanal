# `crates/kaanal/src/main.rs`

The `kaanal` binary: clap CLI, process lifecycle, and a thin HTTP client for the control API. Usage errors exit 1, not clap's default 2 (2 means "not running", R6.3). Every error and warning line goes through `clean()` before it reaches the terminal.

## What it does

Two kinds of commands:

- **Local**: `up` (run the server), `validate` (dry-run the config), `schema` (print the JSON Schema) and `endpoints` (skeleton entries for spec routes).
- **Remote**: `status` and `chaos set|clear` — thin clients that find the running instance via `.kaanal/run.json` and call its control API (rule R2.6: no per-interface logic). `status` prints a 12-wide TYPE column so `external-api` fits.

## Commands

| Command                                                                        | Behaviour                                                                                                                                               |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `up [-c config] [--port p] [--host ip]`                                        | Locks the directory, starts the server, writes `.kaanal/run.json`, prints mock + UI URLs, runs until Ctrl+C.                                            |
| `validate [-c config]`                                                         | Runs `kaanal_server::check`; prints warnings to stderr, `ok: <file>` to stdout.                                                                         |
| `schema`                                                                       | Prints `kaanal_core::config_schema()` as pretty JSON (editor autocomplete). The `# yaml-language-server: $schema=` header is written by `init` (later). |
| `endpoints [-c config] [--write]`                                              | Prints skeleton lines for spec routes with no entry (see the table below). Add-only.                                                                    |
| `chaos set <node> [--latency 300ms] [--error-rate 10%] [--error 503] [--down]` | PUTs a merged patch. With no flags → error "nothing to set" instead of sending an empty patch.                                                          |
| `chaos clear [node]`                                                           | DELETE one node or all.                                                                                                                                 |

### `endpoints` cases

| `endpoints:` in kaanal.yaml | No `--write`     | `--write`                                                                                                  |
| --------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------- |
| a file path                 | Prints the block | Appends it (CRLF kept if the file uses it); refuses if the result would not parse or would lose an old key |
| an inline map               | Prints the block | Prints it too, with a note on stderr; `kaanal.yaml` is never rewritten (R1.17)                             |
| absent                      | Prints the block | Creates `kaanal.endpoints.yaml` and says which line to add; refuses if that file already exists            |
| every route covered         | `nothing to add` | `nothing to add`                                                                                           |

## Exit codes (rule R6.3)

`0` ok · `1` error · `2` not running (no `run.json`, or the instance there is gone). Carried by `Fail(u8, String)`; `main` prints the message to stderr and returns the code.

## Functions

| Function                        | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main` / `run`                  | Entry and subcommand dispatch.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `config_err(path, e)`           | `file:line:col: msg` when the error has a position, else `file: msg`. `validate` and `up` use it with `Located::in_source` for server errors.                                                                                                                                                                                                                                                                                                                                 |
| `located_err(config, src, e)`   | Prints a server load error against the file it is in: the endpoints file (read again for the line and column) when `Located.file` is set, else `kaanal.yaml`. `validate` and `up` use it.                                                                                                                                                                                                                                                                                     |
| `load(path)`                    | Reads + parses config; formats errors as `file:line:col: msg` (R6.1); returns the config's directory for resolving spec files and the source, so later errors can be placed.                                                                                                                                                                                                                                                                                                  |
| `up(config, port, host)`        | Full lifecycle: `private_dir` → `lock_instance` → warn on non-loopback host → token → tokio multi-thread runtime → `serve` → `write_run_file` → `tokio::select!` on server-vs-Ctrl+C → remove `run.json` only if it still holds _our_ token (a newer instance may have replaced it). Under `determinism: realistic` it prints `Seed:  N (determinism: realistic; replay with determinism: controlled and seed: N)` after the `UI:` line.                                      |
| `private_dir()`                 | Creates `.kaanal` private **before** any secret is written (rule R5.8): Unix 0700; Windows ACL replaced with a single grant for the current user. Failure on Windows warns and continues — the token still protects the API.                                                                                                                                                                                                                                                  |
| `restrict_to_current_user(dir)` | Windows ACL via `whoami.exe` (SID lookup) and `icacls.exe` (inheritance removed, one full-control grant), both invoked by **full System32 path** so a planted earlier-PATH exe is never run.                                                                                                                                                                                                                                                                                  |
| `lock_instance()`               | Exclusive `File::try_lock` on `.kaanal/lock`, held for the process's life (rule R6.7). `WouldBlock` → "already running" with the port if known. The OS releases the lock even on a crash, so there is no stale-lock cleanup.                                                                                                                                                                                                                                                  |
| `write_run_file(bound, token)`  | Writes `{host, port, token, pid}` via temp file + rename; `host` is the bound address, or loopback when bound to all interfaces. Temp file + rename (a concurrent `status` never reads half a file); 0600 on Unix.                                                                                                                                                                                                                                                            |
| `read_run()`                    | Reads `(port, token)` back; any malformed piece → `None`.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `call(method, path, body)`      | The control client. `ureq` agent hardened: **proxy disabled** (never leak the token through `HTTP(S)_PROXY`), **redirects disabled** (a redirect could forward the token), 2 s connect / 10 s total timeouts. Connects to `run.json`'s `host` (older files without it → `127.0.0.1`) but always sends `Host: localhost:<port>`, so the server's Host guard (R5.3) passes on any bind address. Missing instance → exit 2; HTTP ≥ 300 → exit 1 with the server's `error` field. |
| `status()`                      | Fetches topology + chaos and prints the aligned table.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `clean(s)`                      | Replaces control characters with `?` — server text can echo user input (a node name) and must never drive the terminal.                                                                                                                                                                                                                                                                                                                                                       |
| `encode_segment(s)`             | Percent-encodes one URL path segment via `percent-encoding` (RFC 3986 unreserved stay, set `SEGMENT`). Used for node names in control URLs.                                                                                                                                                                                                                                                                                                                                   |
| `parse_ms(s)`                   | `300ms` / `2s` / `1m 30s` → milliseconds via `humantime`. A unit is required; overflow is an error.                                                                                                                                                                                                                                                                                                                                                                           |
| `parse_rate(s)`                 | `10%` or `0.1` → 0.0–1.0.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
