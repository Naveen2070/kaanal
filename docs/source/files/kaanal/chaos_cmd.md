# `crates/kaanal/src/commands/chaos.rs`

`kaanal chaos`, `node`, `cycle` and `pins`: patch bodies, paths and the text views of live chaos and pins. Split out of `main.rs` (R3.8); the overview of the commands is in [main.md](main.md).

## Functions

| Function                         | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `node_path(node)`                | `/__kaanal/chaos/<percent-encoded node>`: the `PUT` path of `node down` and `node up`.                                                                                                                                                                                                                                                                                                                                                                                     |
| `node(cmd)`, `for_set(patch, d)` | `node` runs `node down\|up\|list` as in the table above. `for_set` validates `--for` with `ttl_body` (now enforcing 100 ms to 24 h, else `Fail::usage` "bad --for 'V' (100ms to 24h, e.g. 30s)"), puts `ttl` in the patch and returns the `(reverts in D)` suffix; shared by `chaos set` and `node down`. `ttl_body(what, ttl)` takes the flag name for the message and also serves `scenario activate --ttl` (it says `bad ttl`), so that flag is range-checked here too. |
