# `crates/kaanal/src/commands/logs.rs`

`kaanal logs` and `trace`: one-shot and `--follow` reading of the request log, and the output helpers. Split out of `main.rs` (R3.8); the overview of the commands is in [main.md](main.md).

## Functions

| Function                                                                   | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `logs_cmd(args)`, `logs(params, follow, json)`                             | Validate `-n` and `--scope`, build the query pairs, then print the page (`show` per entry) or hand over to `follow_logs`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `follow_logs(params, json)`                                                | `logs -f`. Parses the filters with the server's own grammar first (a bad value fails before anything is opened), then opens `GET /__kaanal/events` with an `Authorization: Bearer` header (never `?token=`), on an agent with no total timeout. A reader thread splits the stream into SSE messages and queues them on a bounded channel (`logview::BACKLOG`, 4096), counting what does not fit; only then it fetches the tail (`GET /logs`), prints it and records the ids in `Seen` (last 2000). `logview::drain` then prints every queued `request` event that `Seen` has not met and `passes` the filter; with `--json` it fetches the full entry (`GET /trace/{id}`) first. A `lagged` notice goes out whenever drops were counted. Ctrl+C exits 0 from its own thread; a `shutdown` event (a `down` or signal drain) makes it wait for the lock to go (the event's `timeout_ms` plus 2 s) and exit 2 with `kaanal stopped (the server shut down)`; a stream that ends without one waits up to 2 s for the lock, then goes through `transport_failure`: exit 2 when the instance is gone, exit 1 `kaanal is running (pid N) but its control API did not answer` when the lock is still held. |
| `trace(key, json)`, `show(v, json)`, `logs_path(params)`, `out_line(text)` | The waterfall command, one log line or JSON object, the `/logs?k=v` path, and the stdout writer: a closed pipe exits 0 quietly, any other write error exits 1.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
