# `crates/kaanal/src/instance/remote.rs`

The thin HTTP client for the control API: one agent, one `call`, `status` and the shutdown reply. Split out of `main.rs` (R3.8); the overview of the commands is in [main.md](main.md).

## Functions

| Function                                             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `post_shutdown(run, budget)`, `control_agent(total)` | `POST /__kaanal/shutdown` with `{"timeout": budget}`; the status, or `None` for no answer. The agent has no proxy, no redirects, 2 s connect timeout and the given total timeout (5 s).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `call(method, path, body)`                           | The control client (GET, PUT, POST with or without a body, DELETE). `ureq` agent hardened: **proxy disabled** (never leak the token through `HTTP(S)_PROXY`), **redirects disabled** (a redirect could forward the token), 2 s connect / 10 s total timeouts. Connects to `run.json`'s `host` (older files without it → `127.0.0.1`) but always sends `Host: localhost:<port>`, so the server's Host guard (R5.3) passes on any bind address. The target comes from `target::resolve()`: the local instance via `lifecycle::require_instance` (a missing or stale one → exit 2, nothing answering with the lock held → exit 1, see [lifecycle.md](lifecycle.md)) or a remote one (no `run.json`); a transport error goes through `Target::unreachable` (locally `lifecycle::transport_failure`, remotely exit 1), and a 401 or `bad Host header` from a remote through `Target::refused`; HTTP ≥ 300 → exit 1 with the server's `error` field. A 204 gives `Value::Null`. An error body's `detail` is appended in parentheses (`HTTP 404: evicted (older than ...)`). |
| `call_text(path)`                                    | `GET path` answered as text (for `sim report`'s Markdown), through the same private `request` as `call`: same target, token, timeouts and error handling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `status()`                                           | Fetches topology, `GET /chaos` and `GET /scenarios/active`, and prints the aligned table from the **`effective`** group (the compiled result, not only the live layer): one cell per node, then `endpoint KEY: ...` and `node @ endpoint: ...` lines, then `active scenarios: ...`. `chaos_text(c)` formats one compiled key: `+Nms`, then one `, P% errors (what)` per failure band (the kind by name unless it is `status`, which shows its code), then `, DOWN`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
