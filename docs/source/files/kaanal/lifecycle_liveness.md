# `crates/kaanal/src/instance/lifecycle/liveness.rs`

Is an instance running: the lock probe, the `run.json` reader and the stale-state cleanup. Split out of `lifecycle.rs` (R3.8); the overview is in [lifecycle.md](lifecycle.md).

## Items

| Item                                | What it does                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Liveness`, `lock_probe(dir)`       | `Running` or `Free` for callers that do not need the guard.                                                                                                                                                                                                                                                                                                                          |
| `Run`, `Startup`, `read_run(dir)`   | The parsed `run.json`: `addr` (host defaults to `127.0.0.1` for older files), `token`, `pid`, and the `startup` object (`auth`, `seed`, `warnings`; none of it secret). Any malformed piece gives `None`; unknown fields are ignored.                                                                                                                                                |
| `read_run_wait(dir, budget)`        | `read_run` retried every 100 ms: the file appears a moment after the lock is taken. `STARTUP_WAIT` is 5 s.                                                                                                                                                                                                                                                                           |
| `remove_stale(dir, token)`          | Deletes `run.json` only if it still holds `token` (a newer instance may have replaced it).                                                                                                                                                                                                                                                                                           |
| `require_instance(dir)`             | What every remote command (`call`, `follow_logs`) starts with. Free + file: `kaanal is not running (removed stale state from a stopped instance)`, exit 2. Free + unreadable file: removed, exit 2. Free + none: `(no .kaanal/run.json)`, exit 2. Held: the `Run`, or exit 1 `kaanal is starting or its state file is missing` after 5 s. Nothing is deleted while the lock is held. |
| `transport_failure(dir, addr, why)` | The failure for a request that got no answer. Lock held: exit 1 `kaanal is running (pid N) but its control API did not answer: why`. Lock free: exit 2 `kaanal is not running on ADDR: why`, and the stale file is removed. A probe error is returned as is.                                                                                                                         |
| `clear_stale(dir)`                  | What `down` and `up -d` do first. `None` when the lock is held (nothing touched). Otherwise removes the stale file and returns the line to print: `kaanal is not running`, `... (removed stale state from pid N)`, `... (removed stale state)` or `... (removed unreadable state)`.                                                                                                  |
| `wait_lock_free(dir, budget)`       | Polls the lock every 50 ms until it is free. A probe that fails counts as not free, so `down` never says "stopped" on a guess.                                                                                                                                                                                                                                                       |
